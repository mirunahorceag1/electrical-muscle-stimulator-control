# electrical-muscle-stimulator-control
Academic team project on the design and OrCAD simulation of digital control logic for an electrical muscle stimulator, using a finite-state machine, logic gates, and D flip-flops.
# Electrical Muscle Stimulator — Control Logic Design

This team project was developed for a course on microprocessor systems and their medical applications at the Faculty of Medical Engineering, Politehnica Bucharest. We designed and simulated the digital logic that controls mode selection for a proposed electrical muscle stimulator.

## What we designed

- A four-state finite-state machine with standby and three operating modes.
- A two-button interface. One button cycles through the operating modes, and the other returns the system to standby from any mode.
- A digital circuit built from logic gates and two D flip-flops. We used a state-transition table and Karnaugh maps to derive and simplify the logic equations.
- An OrCAD simulation to check the state transitions in response to button inputs.
